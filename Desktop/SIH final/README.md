# Shayak AI - SIH Final

Shayak AI is an interactive and comprehensive platform designed to assist patients and caregivers. It features tailored workflows for both roles, integrating cognitive games, AI-driven insights, and seamless tracking.

## 🌟 Key Features

### 🧑‍⚕️ Patient Portal
- **Cognitive Games**: Includes interactive games like Memory Match and Sequence Recall to stimulate cognitive functions.
- **Progress Tracking**: Monitor game results and overall patient progress.
- **Reminders**: Stay on track with daily tasks and medications.
- **Accessibility Settings**: Customizable language and accessibility options for a better user experience.

### 🫂 Caregiver Portal
- **Dashboard**: A comprehensive overview of patient statuses and upcoming tasks.
- **Patient Management**: Add, remove, and monitor assigned patients.
- **Session Tracking**: Detailed logs of patient sessions and activities.
- **AI Decisions**: Leverage Google GenAI for intelligent insights and recommendations.

## 💻 Tech Stack
- **Frontend Framework**: React 19, Vite
- **Styling**: Tailwind CSS v4, Framer Motion (for smooth animations)
- **Routing**: React Router v7
- **Data Visualization**: Recharts
- **Icons**: Lucide React
- **AI Integration**: Google GenAI

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js and your preferred package manager (npm, yarn, or bun) installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shivansh1146/SIH-Final.git
   cd SIH-Final/shayak-ai
   ```

2. Install dependencies:
   ```bash
   npm install
   # or if you are using bun:
   bun install
   ```

3. Set up environment variables:
   Copy the `.env.example` file to `.env` and fill in your necessary keys (like Google GenAI keys).

4. Start the development server:
   ```bash
   npm run dev
   ```
   The app will typically be available at `http://localhost:3000`.
